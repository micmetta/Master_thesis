## GENERAL INFORMATION

In this folder **"docker Container”** there are all the following subfolders and files:

- **data_model**: contains two subfolders "base" and "trained":
  - **base**: contains the basic LLama3 models with 8B and 70B parameters.
  - **trained**: contains the fine-tuned models that were obtained starting from the base models present in the "base" folder.


- **_lib**: contains the **bitsandbytes** subfolder which will be used to install the library that allows you to quantize a 4-bit model.


- **script**: contains two Python scripts and a subfolder called "utils":
  - **inference_8B.py**: contains the code to run the inference with the fine-tuned model Llama3-8B.
  - **inference_70B.py**: contains the code to run the inference with the fine-tuned model Llama3-70B.
  - **utils**: contains two Python scripts:
    - **post_processing_functions.py**: contains the functions used for post-processing the SQL query generated by the model.
    - **stopping_criteria.py**: class that allows you to stop the generation of the model response as soon as a particular stop token is generated.


- **requirements.txt**: contains all Python libraries with the correct versions that will be used to execute all scripts in the **"script"** folder.


- **Dockerfile**: contains all the necessary steps that will be executed by Docker to correctly build the project image.


- **job.sh**: Bash script that will be executed inside the Docker container for:
  - Decide which model to use.
  - Execute the appropriate inference script with the provided parameters such as natural language query.


## 1) How to build the image
  ```bash
  docker build -t docker_container_image .
  ```
