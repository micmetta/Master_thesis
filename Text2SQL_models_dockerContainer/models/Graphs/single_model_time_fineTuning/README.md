## General information

- In this folder there is a single script, **'stackplot.py'**, that allows you to create a stackplot to compare the number of correct and incorrect queries generated by the 8B and 70B models.

- On the x-axis there will be the query categories and along the y-axis the number of queries. Through the colors it is possible to understand, for each model, for each category, how many queries were generated correctly and how many were incorrect.


## 1 - Setting paths

The steps to follow are the following:

- Open the configuration file called **'configuration.env'**.

  - **BASE_PATH**: Assign to this variable the path of your base root on the remote machine. (e.g. "/beegfs/home/mmetta").

  - **RESULTS_MODEL_1**: Assign this variable the **path to the 'category_results.json' file of model-1** obtained after running the script "venvText2SQL/models/Testing/on_dataset_without_postProcessing/test_dataset.py".

  - **RESULTS_MODEL_2**: Assign this variable the **path to the 'category_results.json' file of model-2** obtained after running the script "venvText2SQL/models/Testing/on_dataset_without_postProcessing/test_dataset.py".

  - **LABEL_MODEL_1**: Assigns to this variable the label that will appear on the stackplot and that will represent model-1.

  - **LABEL_MODEL_2**: Assigns to this variable the label that will appear on the stackplot and that will represent model-2.

  - **NAME_OUTPUT_FILE_GRAPH**: Assign to this variable the name of the folder that will contain the stackplot.


## 2 - Run the testing

- To launch the **'stackplot.py' script, after opening the ssh connection with the remote server** perform these steps:

  1) Position yourself on a machine, for example on a Gracehopper:
      ```bash
      srun -p gracehopper --gres=gpu:1 --pty bash
      ```

  2) Active the virtual environment:
      ```bash
      source venvText2SQL/bin/activate
      ```

  3) Add the PyTorch library present on your remote account to the Python package search path, by executing the command (**e.g. <BASE_PATH> = /beegfs/home/mmetta**):
      ```bash
      export PYTHONPATH="<BASE_PATH>/venvText2SQL/models/_lib/pytorch-2.3.0/lib/python3.10/site-packages/"
      ```

  4) Place yourself in the  "Graphs" folder with the following command:  
      ```bash
      cd venvText2SQL/models/Graphs
      ```

  5) Run the script with the command:
      ```bash
      python stackplot.py
      ```


## 5 - Results information
- At the end of the execution:

  - Inside the folder with the path shown below there will be **1 file with the stackplot graph** with .png extension:

      **<BASE_PATH>/venvText2SQL/models/Graphs/Stackplot/<NAME_OUTPUT_FILE_GRAPH>**
