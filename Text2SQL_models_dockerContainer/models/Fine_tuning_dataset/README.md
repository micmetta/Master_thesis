## General information

- In this folder there are **3 subfolders**:

1) **"createDataset"**: Contains the files needed to create a fine-tuning dataset from scratch.

2) **"downloadDataset"**: Contains the files needed to download a new fine-tuning dataset from Hugging Face.

3) **"dataset"**: Contains the files for the test both English and Italian (in the **subdirectory called "test"**) and also contains files to fine-tune an LLM (in the **subdirectory called "training"**).
