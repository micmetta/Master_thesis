## General information

- In this folder there are **2 subfolders**:

1) **"training"**: Contains the datasets used to fine-tune the models during the experimental work.
    - **Text2SQLDataset**: Is the largest dataset with 78,577 examples. It contains generic SQL queries from two datasets called "WikiSQL" and "Spider".
    - **BioInfoDataset**: Is the dataset that uses separate tables for "strain" and "virus". It contains biological database specific queries.
    - **BioInfoDataset_v3**: Is the dataset that uses only "detailedstrain" table. It contains biological database specific queries.

2) **"test"**: Contains the datasets used to test the models during the experimental work.
    - **en**: Contains only English datasets.
    - **it**: Contains only Italian datasets.
        - Both the two subfolders "en" and "it" contain these datasets:
            - **test_set_24**: Contains test sentences based on separate "strain" and "virus" tables.
            - **test_set_21_v3**: Contains test sentences based only on the "detailedstrain" table.
            - **test_set_21_v3_PlusOtherQueries_for_post_processing**: It's like "test_set_21_v3" but with the addition of some queries to evaluate the post-processing implemented by the backend of the application on the queries generated by the Large language model in production. In this case I am not interested in knowing the accuracy value of the model but only in seeing how it actually generates the queries.
